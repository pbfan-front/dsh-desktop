# 有界源码定位与复核包（BEA-056）

## 为什么做这一层

[上一轮真实对话](business-workflow-summary-natural-language-review-2026-10-21.md)已消除工作流回复截断和直接 Mock 大文件读取，但仍用 8 次 grep、6 次源码 read 串行定位字段、实体转换、卡片和枚举。

专项核对区分了三个层次：

- CodeIntell 产物已有部分页面调用、子组件和枚举引用：`index.calledBy` 能指向实体方法和卡片，`graph.json` 有 `CALL`、`CONST_REF` 等关系；不能把所有重复定位都归因于解析器漏解析。
- 当前 Runtime 的字段消费扫描主要读取目标页，`sourceReadPlan` 是读取缓存/并发诊断，不是 Agent 可用的跨文件源码阅读清单。原分析也没有为这类复核消费完整图关系。
- 当前字段倒排项对本例 `duestatus`/`loan_acct_no` 只有类型定义位置，`duestatus_val` 不在该倒排表中。这不能证明完整图/更高层查询器完全没有关系，更不能靠字段同名补成数据流。

本条复用已有图提供**导航位置与当前源码片段**，不另建 AST 解析器，不改业务 CodeIntell、Mock、排序或质量阈值。图的跨文件调用/常量引用不等于 API 字段的数据流或当前执行路径。

## 工具与权限

`business_inspect_source_evidence` 调用 Bearer 鉴权的只读 `POST /__desktop/source/inspect-evidence`：

```json
{
  "evidenceId": "<本会话工作流分析返回的未过期ID>",
  "identifiersJson": "[\"statusLabel\",\"loanId\"]"
}
```

只接受 1–8 个来源明确的 ASCII 标识符，每个最多 80 字符；不是正则、字段路径或业务描述。支持 `$`，按完整标识符边界查找；不支持的写法保留原定向 grep/read。

目标文件、会话和生命周期版本均取自原分析记录，调用者不能提交新路径或覆盖路由。分析过期、重启丢失内存证据、跨会话、生命周期变化或图不可用时拒绝，不延长 evidenceId、不重跑分析、不签发新创建证据。此读取不批准来源，不创建/启用 Profile，不代替确认及最终页面/真实请求门禁。

主要错误：`E_SOURCE_REVIEW_EVIDENCE/410`、`E_SOURCE_REVIEW_SESSION/403`、`E_SOURCE_REVIEW_INDEX/409`；单文件不可读、越界、超限或读中变化作为 `gaps` 返回，不用旧片段顶替。

## 证据来源与预算

实现位于 Desktop `build/business-source-evidence.mjs`，由原 Runtime 组装，新增模块进入 `build.extraResources` 和发布预检。没有新增依赖、服务、持久缓存或 UI 接口。

- 第一次需要源码包时才读取/投影既有 `graph.json`，校验生命周期声明的 SHA-256。投影缓存按当前项目、预期哈希及 dev/inode/size/mtime/ctime 验证；变化则重新读取并校验，没有 TTL 猜测。普通分析不因此解析整份图。
- 只沿已有 `IMPORT/CALL/CONST_REF` 构造最多两跳的页面邻域；支持产物里只有规范 ID、没有独立节点的 synthetic constAccess 引用。阅读优先级只是源码定位预算安排，不影响原场景排名或门禁。
- 每次重新读源码，不缓存旧片段。使用文件描述符限制实际读取量，前后及当前路径核对完整元数据指纹；返回当前内容哈希与完整行文本。真实路径必须在源码根内，不能借索引路径或符号链接读出项目。
- 保留邻近索引锚点/模板首次出现位置，避免密集脚本引用把渲染片段遮蔽。只匹配文字，不把注释当字段消费证明，不从源码内容执行任何指令。

| 维度 | 上限 |
| --- | ---: |
| 图文件 / 节点及边（各自） | 64 MiB / 200000 项 |
| 已探查邻域 / 实际读取 | 64 文件 / 24 文件 |
| 源码读取并发 / 单文件 | 4 / 512 KiB |
| 返回片段 / 同文件片段 | 10 / 3 |
| 每片段上下文 | 锚点前 5 行、后 15 行 |
| 密集文字候选窗口 / 单行 | 前 256 个候选加索引邻近锚点 / 1500 字节 |
| 序列化后的完整回复 | 24000 UTF-8 字节 |

超长行/超预算片段整体省略，不切半行或截取 JSON。覆盖诊断和 `unlocatedIdentifiers` 都是**有界范围内尚未提供的位置**，不是不存在/未使用。计数仅覆盖已经探查的集合，`scopeLimited=true` 时尤其不能当全仓库总量。

返回 `kind=source-location-hints`、`complete=false`、`snapshot=independent-fresh-files`；每个片段带相对文件、startLine/endLine、逐行文本、sourceSha256 和索引关系。`indexedLine` 是原索引位置，只是定位提示；新鲜源码片段不表示图关系已重新解析，多个文件也不是同一时点的原子快照。
