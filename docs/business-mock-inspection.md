# 按 Scenario 与字段结构化读取 Mock

目的：减少 Agent 为核对少量 Mock 字段而反复搜索大文件、试探行号和读取全文。公共只读能力由 Desktop 提供，不针对某个业务场景；不改候选排序、质量分数、来源批准、确认/创建及最终页面门禁。

## 工具与数据范围

新增 Harness 工具 `business_inspect_mock_scenario`，调用已有随机 loopback Runtime 的 `POST /__desktop/mock/inspect-scenario`。只接受 Bearer 鉴权；没有新增 GUI 同源豁免、IPC、任意路径或公网入口。实现复用已进入安装包资源的 `business-mock-store.mjs`，无新依赖、独立服务或索引。

```json
{
  "apiUrl": "/loanNbr/loanNbr.json",
  "scenarioId": "精确的已有Scenario ID",
  "fieldPathsJson": "[[\"data\",\"list\",0,\"loan_acct_no\"],[\"data\",\"list\",0,\"duestatus\"]]"
}
```

工具把 `fieldPathsJson` 转为 Runtime 的 `fieldPaths` 数组；路径相对于 **Scenario.data**，不是 Mock 文件根、baseData 或中间件合成后的 HTTP 响应。上例适用于 Scenario.data 自身含业务 `data` 信封的配置，不能对所有 API 机械套用。

- API/Scenario 必须使用已发现的精确 ID，不按 label、近义词、默认场景或拼写变体猜测。
- 当前用户 Overlay 优先，其次项目源码；命中 Overlay 文件后，缺少该 Scenario 也不降到源码找同名场景。不合并 baseData，也不把 absent 当作“最终响应没有该字段”。
- 每次直接读取当前文件，不新增 TTL 或分析缓存；同一响应中的字段来自同一份解析结果。确认到创建之间的文件变化仍由原实时复核处理，读取快照不是事务锁或未来有效性承诺。
- 接口只返回规范 API 映射出的 Mock 文件；物理路径超出声明 source/user root 的符号链接拒绝，解析错误不回显 JSON 内容。不会返回凭据、任意文件或签发 evidenceId。
- 数组和对象型 scenarios 沿用现有 ID 语义；数组重复 ID 拒绝。未知 API/ID、非法路径、文件无效分别返回稳定错误码，不伪装成功。

## 有界结果，不返回伪完整数据

未传字段路径时只返回 Scenario.data 根结构。传入路径后，每个字段明确区分：

- `present=false`：该路径在选定 Scenario.data 中不存在。
- `present=true, complete=true, value=...`：该选定节点的完整原值，字符串、数字、布尔、null 与空值不转换。
- `present=true, complete=false, shape=...`：只含类型/长度或有界键名摘要，没有半截 value；须继续缩小路径或回到精确源码检查。

最多 16 条路径、深度 12；对象键是安全标识符，数组索引是 0–1000 的整数，禁止原型字段。单个选定值最多 8192 字节、合计 16384 字节，额外以节点/嵌套预算限制展开。结构摘要仅展示前 8 个符合限制的键名，返回总数及省略数。特殊键名、深结构或超出索引范围的需求保留源码检查回退，不宣称全部写法均已覆盖。

`fullScenario=false` 始终明确这是数据投影，**不是完整 Scenario 配置**，即使某个 value 完整也不含所有 mode、delay、请求匹配等附带配置。复用仍提交已复核 `sourceScenarioId`，由原 Runtime 克隆完整原配置；不可从投影重建或擅自净化业务字段。

## Agent 使用与回退

原有分析结果的有界预览足够时无需额外调用；缺少必需字段时，先按已证实 API/Scenario 读取精确路径。失败、特殊字段或信息不足时保留定向源码搜索与行区间读取，确有缺口才扩大检索。新工具不证明业务字段消费、来源已批准、同一卡片关联或最终页面通过。

这是附加只读工具，无新的分析模式开关。可以继续使用原定向 grep/源码读取流程；不调用此工具不改变默认分析/创建行为。完全回退时一并移除工具注册/提示与对应只读端点/方法，不需要清空 Profile、删除分支或修改 Mock 数据。新插件连接旧 Runtime 会得到端点不可用错误，须走原检索回退，不能把错误结果当成通过。
