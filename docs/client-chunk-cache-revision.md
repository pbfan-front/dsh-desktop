# 体验结果卡片隐藏后仍显示：子文件缓存修复

## 原因与修改

业务 UI 已在 `client.experience-flow.js` 中隐藏完成状态的结果卡片，但插件加载器的不可变资源版本此前只计算入口 `client.js` 的文件元数据。只修改延迟加载的子文件时，URL 版本不变，客户端可能继续使用旧缓存，因此组件测试通过后实际客户端仍显示旧卡片。

目标依赖为 `@deepseek-ai/dsh-client-modules@0.2.0-rc.2`。现有 patch 增加同目录 `client.*.js` 子文件的排序元数据摘要，并将其纳入入口资源版本。插件注册或重新构建时，新增、修改或删除子文件都会改变资源版本；不扫描无关文档，不清理用户会话或分支。此修改不新增对子文件的实时监听。

补丁位置：`patches/@deepseek-ai+dsh-client-modules+0.2.0-rc.2.patch`。上游将延迟子文件纳入不可变资源版本，或提供等价的独立子文件版本后，可移除对应补丁。

## 验证

- 缓存版本回归测试覆盖新增、修改、删除子文件，以及无关文档不改变版本。
- 相关 6 个测试文件、16 项测试通过，TypeScript 检查通过。
- 在隔离临时目录安装同版本原始依赖，成功重放补丁，并核对生成文件与当前依赖一致。未执行整个项目的全新 `npm ci`。
- 重启当前 Electron 开发客户端，在原会话确认“检查已通过”结果卡片消失；保留原会话和体验分支。
- 实际截图：`docs/screenshots/completed-card-hidden.png`。
