# 默认数据体验分支快速创建（BEA-062）

2026-10-24 用户确认：“创建合并套餐页的体验分支”表示按默认页面数据直接新增分支，无需先指定某个业务状态。

## 行为

页面名称由原 CodeIntell 路由解析器定位，明确路由仍须由用户提供或从歧义候选中选择。`business_create_default_branch` 一次调用完成解析与新增；不进入自定义场景的来源研究、方案准备和确认流程。自定义贴息、套餐、字段、Scenario 或跨页验证仍走原 `business_start_scenario_workflow`。

新增 Profile 包含路由、标签和 `dataMode=default` 标记，`apis={}`，不改写任何 Mock。请求继续使用当前默认 Mock 选择规则：这是一条继承默认数据的分支，默认配置后续变化时它也跟随变化，并非冻结快照，也不复制当前会话选中的 Profile。来源完整性仍由现有包与索引加载检查负责。

创建只新增分支。当前会话、URL、激活 Profile 和 revision 保持；用户在业务体验中点击“体验”才切换。返回结果明确 `applied=false, verified=false`，不把创建或默认数据一致当成页面验证通过。没有创建需要用户继续操作的验证工作流。

Mock Platform 已有可见时每 1.5 秒读取分支列表的行为；新分支通过原 `/api/profiles` 返回，按 routePath 进入页面分组。列表展示与路由导航沿用现有实现。需要前置业务信息的页面仍有原有运行条件，本轮不构造新的业务会话或执行真实业务提交。

## 输入与写入边界

- 新工具只接受 profileId、原 query、字面页面名/用户明确路由及可选标签；未知字段、data、API/Scenario 覆盖拒绝。必须明确提供页面名或路由，不能静默回落到当前其他页面。
- 解析歧义返回候选且不写文件；用户选择后使用同一 profileId 重试。插件已声明的业务意图匹配时拒绝默认数据路径。该匹配不是通用语义分类；模型还需遵循工具用途并完整保留用户需求。
- 同一会话、ID、路由和标签重复请求返回原分支；其他重名冲突拒绝，不覆盖已有分支。相同内容的新建请求应使用新 ID。
- Runtime 对 Profile 新增、场景创建、导入、回滚共用叶子请求写入队列，避免默认路径与原路径同时修改 Profile 文件。工作流桥不持有该队列，避免嵌套请求死锁。
- 默认分支的恢复材料先于 Profile 发布保存；正常回滚仅删除对应 operationId 的未变更分支，保留后来创建的分支。若分支已被后续编辑替换，拒绝回滚覆盖。原自定义场景回滚协议保持。
- 空 API Profile 只有带本功能版本标记、默认数据模式且没有外部能力覆盖时才能选择。原来无绑定且未标记的 Profile 仍拒绝。

## 验证与实测

现有真实插件/进程桥加默认分支回归覆盖：未鉴权拒绝、会话身份、未知字段、明确业务状态拒绝、歧义不写入、并发新增、重试幂等、重名保护、空绑定选择限制、默认 API 数据一致及选择/返回默认/回滚。原创建工作流与分发资源回归一并检查。

最终 5 个相关测试文件、56 项回归通过，另有 TypeScript 检查、`scripts/test-business-runtime.mjs` 原场景创建/请求/验证/缓存集成回归和 JS 语法、差异检查通过。本轮没有运行全量测试；Runtime 回归中的 `browserOutcomeVerified` 为该脚本的原有受控页面观测，不是本功能的实际浏览器验收。

使用业务工程正式导出脚本创建临时业务包，包含新增的“合并套餐页”别名；按 package.json 分发清单搬迁 Runtime 所有模块，独立用户目录启动新进程，通过真实注册工具传入原请求“创建合并套餐页的体验分支”和字面 targetPage。目标解析为 `/loan/fullLoanApply`，列表 API 可见且健康，当前激活状态不变。受控选择后 `/loan/queryPkgListV3.json` 的 data 与默认请求完全一致，精确回滚成功。

最新一次工具往返 5.22ms，Runtime 约 2.01ms（目标解析约 0.80ms）。这是已启动进程中的工具阶段采样，**没有调用模型，不是整轮自然语言耗时或真机页面验收**。没有改写活动客户端、现有会话、Profile 或业务 Mock。临时导出和用户目录在验收后删除。

本轮实现未提交，未替换活动开发/安装包。回退时成组恢复本功能模块、Runtime 接入、分发条目与工具提示。已经创建的默认数据分支应先返回默认并按 operationId 精确移除；旧 Runtime 不支持选择零绑定分支，不应把它误认为可直接运行。
